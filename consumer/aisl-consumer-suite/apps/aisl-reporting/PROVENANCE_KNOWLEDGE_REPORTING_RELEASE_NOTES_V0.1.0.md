# aisl-reporting 0.1.0

First vertical slice of the new reporting architecture:

- typed `ReportRequest`, dataset and run manifest contracts;
- `system-description/v1` deterministic builder over public KLC queries;
- exact evidence index, representative journeys and diagram-ready relations;
- short renderer prompt;
- dataset and Markdown validation;
- old/new report regression harness;
- no preliminary LLM analysis and no `final_response.json`.
