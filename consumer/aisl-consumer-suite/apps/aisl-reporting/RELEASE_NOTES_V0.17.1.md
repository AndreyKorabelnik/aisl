# aisl-reporting 0.17.1

## Large data-model revision reporting

`data-model-report/v1` теперь формирует ограниченный по размеру, но доказательный dataset для крупных объединённых revision.

- Бюджет `500000` байт не повышен.
- Полные API DTO не копируются в каждый выбранный объект и физическую таблицу.
- Сохраняются имена, типы, ключевые свойства, связи, PDM-коды, source file и сведения о полноте.
- Усечение выборок всегда отражается отдельными счётчиками и flags.
- Детерминированные ER-диаграммы продолжают строиться из dataset, а не renderer-моделью.
- Скрытого fallback, name-similarity inference и чтения legacy combined DuckDB нет.
