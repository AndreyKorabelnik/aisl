# Knowledge Layer Core 0.61.0a25

Repository Inventory v2 is a bounded technical passport over official evidence. It adds identity, composition, technologies, concept evaluation state, normalized interfaces/inputs/outputs, storage/data footprint, coverage, structural families, novelty/UNCLASSIFIED and diagnostics. Expensive optional evidence is consumed when already available but is not produced by default. Interaction classification uses observed boundary counts and does not guess peer systems.
