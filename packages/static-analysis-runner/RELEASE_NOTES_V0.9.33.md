# static-analysis-runner 0.9.33

## Детерминированная идентичность топологии

- `snapshot_id` теперь вычисляется только по portfolio fingerprint и стабильным результатам репозиториев;
- временные метки, локальные output paths и тексты ошибок больше не влияют на identity топологии;
- одинаковый набор репозиториев, commit, профилей и результатов даёт одинаковые `snapshot_id`, `island_id` и `topology_fingerprint`;
- изменение commit или стабильного результата анализа изменяет snapshot identity.

Проверка выполнена двумя независимыми сборками KLC поверх компактных результатов четырёх реальных приложений.
