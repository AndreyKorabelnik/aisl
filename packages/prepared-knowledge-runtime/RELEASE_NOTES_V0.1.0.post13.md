# prepared-knowledge-runtime 0.1.0.post13

Adds deterministic read support needed by object-centric data-model consumption.

- Reads exact logical-storage mappings by declared object identity.
- Reads model-storage identities, references, key lineage and reference-value derivations by exact source FQCN.
- Preserves published mapping status, basis, knowledge class, provenance payload and gaps.
- Does not infer storage semantics when the corresponding knowledge product is absent.
