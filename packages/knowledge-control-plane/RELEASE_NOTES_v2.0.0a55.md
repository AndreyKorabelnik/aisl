# Analysis UI 2.0.0a55

## Исправлено

- Mermaid-блоки отчётов нормализуются непосредственно перед отрисовкой.
- Flowchart-подписи узлов автоматически заключаются в кавычки, а подписи рёбер приводятся к каноническому виду `-->|...|`.
- В `erDiagram` физические имена со схемой, например `mbk_cache.card`, автоматически заключаются в кавычки.
- Исправление применяется и к уже опубликованным ревизиям; повторный анализ не требуется.

## Совместимость

- `package.json` и `package-lock.json` не изменялись.
- Для режима `npm run dev` достаточно обновить исходники; `npm ci` не требуется.
- Для заранее собранного production frontend требуется повторить только `npm run build`.
