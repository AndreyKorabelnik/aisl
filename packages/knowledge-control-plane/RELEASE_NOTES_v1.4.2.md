# UI2 v1.4.2 — принудительный повтор LLM-анализа

## Страница запуска

Добавлен флаг **«Повторно выполнить LLM-анализ и отчет»**. По умолчанию он выключен.

При включённом флаге UI:

- проверяет текущий commit репозитория как обычно;
- переиспользует валидный результат выбора профилей;
- переиспользует валидный статический анализ;
- не переиспользует основной LLM-анализ;
- заново запускает генерацию пользовательского отчёта.

## Изоляция результатов

Принудительный запуск не перезаписывает обычный reusable cache. Для него создаются отдельные task-scoped LLM bundle и отчёт, привязанные к конкретной задаче.

Это позволяет:

- сравнивать разные ответы вероятностной модели на одних и тех же фактах;
- безопасно демонстрировать повторное рассуждение модели;
- продолжать использовать обычный кэш в следующих запусках без флага;
- вести агентный чат именно по результату выбранного принудительного запуска.

## Пользовательская лента

При включённом флаге отображается отдельное событие:

> LLM-анализ будет выполнен повторно
>
> Готовый LLM-результат не используется: модель заново проанализирует те же факты, после чего отчёт будет сформирован повторно.

## Совместимость

Изменения затрагивают только UI. Обновление `code-analyzer-core`, `evidence-llm-pipeline`, `evidence-common` и `llm-prompts` не требуется.
