# Analysis UI 2.0.0a56

## Grounded Mermaid diagrams in chat

Analysis UI now requires Knowledge Assistant 0.14.8, whose canonical chat policy mandates and runtime-enforces Mermaid for explicit diagram requests and diagram-worthy multi-component explanations. The existing Mermaid renderer from 2.0.0a55 renders these answers in standard revision and prepared chats.

Frontend sources and npm dependencies are unchanged.
