# UI2 v1.3.0 — живая лента выполнения анализа

- Backend в реальном времени читает `diagnostics/runtime_events.jsonl`, выпускаемые `code-analyzer-core` и `evidence-llm-pipeline`.
- Пользовательские события передаются через существующий WebSocket и сохраняются в состоянии задачи для восстановления после обновления страницы.
- Frontend показывает ленту этапов, итерации LLM и безопасные сведения о дополнительных evidence-запросах.
- UI отображает готовые `title` и `message` от producer без перевода технических фаз.
- Поллинг сохранён как резервный транспорт при недоступном WebSocket.
- Лента ограничена 250 последними событиями на задачу.

Минимальные совместимые версии:

- `code-analyzer-core >= 0.23.69`;
- `evidence-llm-pipeline >= 0.23.38`.
- Чтение JSONL устойчиво к моменту, когда файл прочитан между двумя частями одной дописываемой строки: незавершённая запись сохраняется и дочитывается, а не теряется.
- Русские подписи статусов дополнительных evidence-запросов поступают от pipeline; frontend не переводит их самостоятельно.
