# UI2 v1.4.7

## Осознанный переход к отчёту

После завершения анализа UI больше не переходит к отчёту автоматически.

На странице хода анализа сохраняются:

- вопрос пользователя;
- прогресс 100%;
- последняя операция;
- раскрываемый полный журнал выполнения.

Переход к отчёту выполняется только по кнопке «Перейти к отчёту».
Повторное открытие завершённой задачи также сначала показывает ход анализа.

Дополнительно удалён технический fallback, который при недоступном `report.md` показывал JSON результата задачи вместо отчёта.
