# UI2 v1.4.4 — упрощённый экран выполнения анализа

## Изменения

- Удалено временное сообщение о пятисекундной загрузке приложения.
- Вопрос на странице запуска по умолчанию: `Подготовь описание системы`.
- На странице выполнения явно показывается вопрос, на который отвечает pipeline.
- Удалена постоянная техническая таблица с идентификатором задачи, моделью, статусом и процентом выполнения.
- Вместо постоянно раскрытого журнала показывается компактная карточка текущей операции.
- Полный журнал событий раскрывается по кнопке `Показать весь ход анализа` и сворачивается обратно.
- Карточка текущей операции использует готовые русские `title` и `message`, опубликованные анализатором и pipeline. UI не интерпретирует технические фазы.
- Существующий подробный журнал, дополнительные evidence-запросы и их безопасные сведения сохранены без изменений.

## Совместимость

Изменён только frontend UI. Backend API, кэширование, сохранение задач и история чата не менялись.

Минимальные версии остаются прежними:

- `code-analyzer-core >= 0.23.69`;
- `evidence-llm-pipeline >= 0.23.38`;
- `UI2 >= 1.4.4`.

Новые npm- и Python-зависимости не добавлялись.
