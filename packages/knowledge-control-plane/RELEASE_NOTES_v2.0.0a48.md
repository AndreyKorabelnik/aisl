# Analysis UI 2.0.0a48

## Технический журнал UI и Knowledge Assistant

- Добавлен сохраняемый технический журнал для каждого контекста чата.
- В интерфейсе чата появился раскрываемый журнал стадий, обращений к Knowledge API и ошибок.
- Ошибка помощника теперь показывает безопасную причину и `request ID`, а не только общий текст 502.
- Добавлены API `GET/DELETE /api/v1/assistant-contexts/{context_id}/logs`.
- Добавлен вращаемый backend-журнал `${ANALYSIS_UI_RUNTIME_ROOT}/logs/analysis-ui.log`.
- Добавлен `GET /api/v1/diagnostics/runtime-log` для получения последней части общего журнала.
- Все HTTP-запросы получают корреляционный `request ID` в заголовке ответа.
- Текст вопросов, credentials, токены и содержимое TLS-материалов в журналы не записываются.
