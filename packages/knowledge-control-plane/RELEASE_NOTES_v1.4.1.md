# UI2 v1.4.1

## Страница результатов

- Удалены кнопки скачивания и показа/скрытия отчёта с финальной страницы анализа.
- После завершения анализа отчёт загружается и отображается автоматически.
- Во время получения отчёта показывается skeleton; при отсутствии содержимого выводится явное предупреждение.

## Mermaid

- Отчёт и ответы агентного чата используют один компонент `Renderer`.
- Mermaid fenced blocks извлекаются до Markdown-рендеринга и больше не оказываются в некорректной структуре `<pre><div>`.
- Каждый Mermaid-блок рендерится независимо через `mermaid.run()` после обновления DOM.
- Ошибка одной диаграммы не мешает отображению текста и остальных диаграмм; вместо неё показываются исходное описание и понятное сообщение.
- UI больше не изменяет содержание Mermaid-диаграмм эвристическими заменами `PK/FK`.
- Исправлено дублированное объявление переменной в обработчике перемещения увеличенной диаграммы.
- Для Mermaid включён `securityLevel: strict`.

## Совместимость

Изменения затрагивают только UI. Версии анализатора, pipeline и prompt pack менять не требуется.
