# Analysis UI 2.0.0a53

## Нормализация адреса Knowledge API

Клиент публикации теперь принимает оба варианта `KNOWLEDGE_API_BASE_URL`:

- `http://127.0.0.1:8080`;
- `http://127.0.0.1:8080/api/knowledge/v1`.

В обоих случаях используется канонический корень `/api/knowledge/v1`. Это устраняет ошибочный запрос к корневому `/health` и последующее ложное сообщение `Knowledge API is unavailable` при работающем сервере.

## Диагностика

При сетевой ошибке в details теперь сохраняются:

- нормализованный `base_url`;
- фактический API path;
- безопасная причина исключения.

Секреты и содержимое артефактов не журналируются.

## Повторный запуск

Задание, упавшее только на публикации, можно повторить с этапа `publication`; checkout, анализ, материализация и отчёт повторно не выполняются.
