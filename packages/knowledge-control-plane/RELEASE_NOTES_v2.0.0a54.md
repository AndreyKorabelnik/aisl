# Analysis UI 2.0.0a54

## Исправлено

- Минимальная версия `knowledge-assistant` повышена до `0.14.7`.
- Установка Analysis UI больше не допускает старый агентный JSON-парсер, который падал на JSON, обёрнутом моделью в Markdown, `<think>` или поясняющий текст.

## Совместимость

- Frontend и его зависимости не изменялись.
- Для обновления необходимо сначала установить `knowledge-assistant 0.14.7`, затем переустановить Analysis UI editable-пакетом.
